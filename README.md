# Login 3D

Halaman login dengan efek 3D: kartu miring mengikuti gerakan mouse, melayang pelan, dan berputar saat berpindah antara Masuk dan Daftar. Dua kubus 3D berputar di latar belakang.

**Lihat langsung:** https://ezsaaa.github.io/Login-3d/

## Fitur
- Pendaftaran dan login akun
- Password disimpan dalam bentuk hash (SHA-256), bukan teks asli
- Animasi 3D dengan CSS murni
- Tampilan menyesuaikan layar ponsel dan komputer

## Dibuat dengan
HTML, CSS, dan JavaScript. Tanpa library tambahan.

## Catatan
Akun disimpan di browser pengunjung (localStorage), jadi ini contoh tampilan dan alur. Untuk sistem login sungguhan, data perlu disimpan di server.

## Cara menjalankan di komputer
1. Unduh atau clone repository ini.
2. Buka file `index.html` di browser.
